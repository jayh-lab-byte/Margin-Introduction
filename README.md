# 여백 — 문장과 사유

프레임워크 없는 HTML / CSS / ES2022 기반 개인 명언·성찰 PWA.

## 실행

`python3 -m http.server 4173 --directory dist`

브라우저에서 http://localhost:4173 을 엽니다. Service Worker는 localhost 또는 HTTPS에서 동작합니다.

## 구현

- 현지 날짜별 고정 명언, 날짜와 문장 ID 저장, 자정/앱 복귀 시 갱신
- IndexedDB(reflections/settings/dailyQuotes), 지원 불가 시 LocalStorage 대체
- 작성·수정·새로고침 지속, 저장 실패 시 작성 내용 유지
- 날짜별 보관함, 같은 명언의 과거 생각 비교
- 시스템/라이트/다크, AI 배경 3종
- JSON 내보내기, 확인 대화상자를 통한 전체 삭제
- 명언 공유/복사 (개인 기록 제외)
- 정적 자산·배경 오프라인 캐시, 설치용 manifest·아이콘
- 키보드 포커스, textarea 레이블, 상태 알림, 동작 줄이기, 320px+ 반응형
- 개인 기록의 서버 전송·분석 도구 없음

## 범위 및 데이터 주의

알림, 계정, 동기화, 검색, AI 추천은 포함하지 않습니다. JSON 가져오기도 포함하지 않습니다. 브라우저 기록 삭제 시 앱 기록도 삭제되므로 내보내기로 백업해야 합니다. 저장 공간 차단 시 오류 화면을 표시합니다. 오프라인 기능은 첫 방문과 캐시 준비 이후 작동합니다. 로컬 미리보기와 배포 주소는 다른 저장 공간입니다.

16개 문장은 고전 저작의 자체 한국어 번역·의역입니다. 각 문장에 참고 판본 링크와 절을 기재했습니다. 학술 번역 및 출판 전 검수는 완료되지 않아 verified=false를 유지합니다. 배경은 built-in imagegen으로 생성했습니다. 프롬프트와 경로는 IMAGE_PROMPTS.md를 참고하세요.

사이트 소스는 dist/입니다. 서버/빌드 의존성이 없습니다.

## 제품 소개 랜딩 페이지

`dist/index.html`은 여백 앱을 소개하는 스크롤형 랜딩 페이지입니다. 심오한 우주색 배경에서 시작해 스크롤할수록 밝은 표면과 제품 화면이 드러나며, `dist/app.html`에서 실제 명언 앱을 엽니다. 기존 PWA 기능은 그대로 유지됩니다.
